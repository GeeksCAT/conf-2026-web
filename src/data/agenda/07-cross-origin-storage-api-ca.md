Avui dia, cada lloc web descarrega i emmagatzema la seva pròpia còpia d'arxius pesats com models d'IA, mòduls WebAssembly, fonts web i llibreries JavaScript populars. Si dos webs fan servir el mateix fitxer, el navegador el descarrega dues vegades.

En aquesta xerrada, Thomas Steiner presenta la Cross-Origin Storage (COS) API: una proposta de memòria cau compartida on els fitxers s'identifiquen pel seu hash SHA-256 i no per la URL. Es mostraran tant l'API imperativa de JavaScript com les formes declaratives mitjançant atributs d'importació, HTML i CSS, amb demostracions en directe.

Després d'aquesta sessió, sabreu com fer servir COS en els vostres projectes per evitar descàrregues redundants i estalviar espai d'emmagatzematge arreu de la web.
