A lightning talk presenting a dual-environment security setup: a normal "heaven mode" for day-to-day coding and meetings, and an "hell mode" where unauthorized users boot into a virtualized, honeypot Windows sandbox requesting the device's return while logging all activities.

We will cover full disk encryption with TPM 2.0, BIOS lockdown, persistent remote access via WWAN eSIM, disposable snapshots, and defensive telemetry.
